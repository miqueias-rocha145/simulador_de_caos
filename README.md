# 🏋️ Simulação de Organização de Halteres em Academia

Este projeto é uma mini simulação em Python que modela o comportamento de usuários em uma academia e o impacto da organização dos halteres ao longo do tempo.
O sistema utiliza conceitos de Programação Orientada a Objetos (POO), aleatoriedade e análise de dados para medir o nível de “caos” gerado pelos usuários durante os treinos.

---

## 🚀 Funcionalidades

- Simulação de retirada e devolução de halteres;
- Usuários organizados e bagunceiros;
- Cálculo do índice de desorganização da academia;
- Reinício automático do ambiente a cada ciclo;
- Geração de distribuição estatística utilizando Seaborn.

---

## 🛠️ Tecnologias Utilizadas

- Python
- Random
- Seaborn

---

## 📚 Conceitos Aplicados

- Programação Orientada a Objetos (POO)
- Simulação de eventos
- Estruturas de dados
- Estatística básica
- Visualização de dados

---

## 🎯 Objetivo do Projeto

Analisar como pequenos comportamentos individuais podem impactar a organização geral de um ambiente compartilhado, utilizando simulações computacionais e visualização gráfica.

---

## 📈 Exemplo de Resultado

Ao final da execução, o projeto gera um gráfico demonstrando a distribuição do nível de caos na academia após múltiplas simulações.

## ▶️ Como Executar

Abrir Folder no VS CODE

Criar ambiente virtual com o seguinte código no terminal:
```
python -m venv venv
```
Ativar ambiente virtual com o seguinte código no terminal:

Caso Windows:
```
 venv\Scripts\activate
```
Caso MAC:
```
 source venv/bin/activate
```
Instalar bibliotecas necessárias com seguinte código no terminal:

```
pip install -r requirements.txt
```
